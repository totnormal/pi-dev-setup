# Example Transformations

See `transformations.json` for machine-readable examples. This file summarizes the coverage:

1. Vague general request -> clarification-ready improvement prompt.
2. Coding request -> inspect-first implementation prompt.
3. Debugging request -> root-cause and validation workflow.
4. Architecture design -> options, tradeoffs, and assumptions.
5. Read-only audit -> non-mutating readiness assessment.
6. Research brief -> source-backed competitor research.
7. Strategy discovery -> executive question framework.
8. Documentation -> API docs workflow.
9. Feature implementation -> scoped product engineering prompt.
10. Deployment -> approval-gated release workflow.
11. Incomplete prompt -> focused clarifying questions.
12. Tool workflow -> connector-aware subscription audit.
13. Destructive production request -> strict safety and approval workflow.
