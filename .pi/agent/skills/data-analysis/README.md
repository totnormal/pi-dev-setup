# Data Analysis Plugin

**15 analysis, auditing, research, and reporting tools**

## What's Included

### Security & Compliance
- **security-best-practices** - Security hardening guidance
- **security-ownership-map** - Security responsibility mapping
- **security-threat-model** - Threat modeling and analysis

### Performance & Quality
- **performance-reporter** - Performance metrics and reporting
- **domain-authority-auditor** - Domain authority evaluation

### Research & Documentation
- **notion-spec-to-implementation** - Notion specs to implementation workflow
- **notion-research-documentation** - Research documentation in Notion
- **notion-meeting-intelligence** - Meeting notes and intelligence extraction
- **notion-knowledge-capture** - Knowledge base creation and management

### Tools & Infrastructure
- **openai-docs** - OpenAI documentation and integration reference
- **atlas** - Data mapping and documentation
- **alert-manager** - Alert system setup and management
- **memory-management** - Context and memory optimization
- **geo-content-optimizer** - Geographic content analysis

## Auto-Activation

Skills activate automatically when Claude detects:
- Security and compliance work
- Data analysis and reporting
- Research and documentation tasks
- Knowledge management
- Performance monitoring

## Quick Start

```markdown
"Create a security threat model for my app"
"Document our API specifications in Notion"
"Generate a performance audit report"
"Set up security best practices checklist"
"Build a knowledge base for my team"
```
