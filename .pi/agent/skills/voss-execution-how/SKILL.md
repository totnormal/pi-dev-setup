# Guarantee Execution with “How”

## R — 原文 (Reading)

> “Yes” is nothing without “How.”
>
> — Chris Voss, Chapter 8 — Guarantee Execution

---

## I — 方法论骨架 (Interpretation)

Agreement is not success; implementation is success. Voss checks commitment by asking “How” repeatedly, testing verbal/nonverbal alignment, using the Rule of Three, watching pronouns, and surfacing decision-makers not at the table. The point is to make the counterpart own the operational path. A real yes has a who, how, by-when, resources, blockers, and stakeholder map.

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **Ask How**
   - 动作: Ask How: require the counterpart to describe implementation in their own words.
   - 完成标准: 能产出可检查的文本、问题、判断或下一步。

2. **Validate three ways**
   - 动作: Validate three ways: get commitment via summary, detail question, and next-step confirmation.
   - 完成标准: 能产出可检查的文本、问题、判断或下一步。

3. **Map stakeholders**
   - 动作: Map stakeholders: identify blockers, approvers, implementers, and pronoun signals that show ownership or distance.
   - 完成标准: 能产出可检查的文本、问题、判断或下一步。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- Do not mistake interrogation for validation; keep questions collaborative.
- If authority is absent, do not treat table agreement as final.
- Do not proceed when “how” answers stay abstract.

### 作者在书中警告的失败模式

- 不要把谈判当成战斗、辩论或单纯的价格拉扯; 先发现真实约束。
- 不要追逐表面 “Yes”; 没有 “How” 的 yes 可能毫无执行力。

### 作者的盲点 / 时代局限

- 本书来自 FBI/危机谈判背景, 现实商务/亲密关系中权力、法律和长期关系约束更复杂。
- 书中战术很强, 但若脱离伦理边界, 容易滑向操控。
