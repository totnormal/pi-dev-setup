# Avoid Brand Architecture Pitfalls

## R — Reading

> "A brand extension or brand endorsement should be a vehicle to support and enhance the key master brand associations. ... If there is no organizational unit to prevent this brand extension or brand endorsement promiscuity, real brand equity damage may result."
>
> — Aaker & Joachimsthaler (2000), p. 18

> "Channel conflict can preclude using established brands; the problem usually is twofold. First, an existing channel may be motivated to stock and promote a brand because it has some degree of exclusivity. ... Second, an existing channel will support a higher price in part because it provides a higher level of service."
>
> — Aaker & Joachimsthaler (2000), p. 21

---

## I — Methodology skeleton (Interpretation)

Four failure modes to police:

1. **Dilution / promiscuity** — letting business units borrow the name for credibility while ignoring image impact. A link should *enhance* key master associations, not just borrow them. Say no to over-stretch (Clorox = bleach; Levi's = casual; Bayer on non-aspirin diluted aspirin ownership).
2. **Credibility dependency** — a new brand needs both a value prop AND credibility; attaching a strong organizational brand (Quality-HP, Innovation-Shiseido, Trust-Sears) removes the credibility hurdle for risky/breakthrough offers.
3. **Channel conflict** — an established channel resists a brand sold through a competing/value channel (breaches exclusivity; undercuts high-margin support). Different brands per channel (L'Oréal/Lancôme/Maybelline; VF's Lee/Wrangler/Maverick/Old Axe; Purina ProPlan specialty vs Purina One grocery).
4. **Identity anarchy vs mediocre compromise** — same brand across contexts needs a *limited* set of identities sharing common elements, not dozens and not one forced compromise.

**M&A retention rule:** keep an acquired name when the customer bond is strong/difficult to transfer (resources to change unavailable; strong associations; emotional bond; fit problem). Schlumberger kept Anadrill/Dowell/GeoQuest (co-driver subbrands); Nestlé usually retains acquired names. HP renames all to HP (defensible only via strong branded-house logic). Beware name changes driven by ego/convenience.

## A1 — Application in the source

### Case 1: Sunkist on candy/soda
- **Risk**: places core orange/vitamin-C franchise in jeopardy; customers don't separate.
- **Lesson**: protect the master's core association.

### Case 2: Hidden Valley Ranch (no Clorox)
- **Risk**: bleach-taste specter if linked.
- **Action**: label says "HVR Company"; no Clorox mention even on back.

### Case 3: Gap Warehouse → Old Navy
- **Risk**: "Gap Warehouse" would cannibalize and associate Gap with low price.
- **Action**: separate brand (house-of-brands) for the value end.

### Case 4: Schlumberger retains acquisitions
- **Reason**: strong customer bonds, distinct cultures; renaming wastes assets.

## E — Execution steps

1. **Inventory master associations** — what MUST be protected (Clorox=bleach, Sunkist=orange/vitamin C).
   - Done when: a "do not violate" list exists.
2. **Gate every extension/endorsement** — does it *enhance* a key master association? If only borrows credibility → block or use house-of-brands/endorsed.
3. **Check channel fit** — would this brand in this channel breach another channel's exclusivity/margin? If yes → separate brand.
4. **M&A test** — is the acquired bond strong & hard to transfer? If yes → keep (co-driver); else → branded-house rename only if master logic is strong.
5. **Set identity discipline** — define the *limited* identity set; forbid anarchy and single-compromise.

## B — Boundary

### Don't use for
- Choosing a position (use aaker-relation-select-separation).
- Designing the spectrum map (use aaker-relation-spectrum).

### Failure modes warned by the authors
- Brand "promiscuity" with no gatekeeper unit → real equity damage.
- New brands justified by wishful "deserves its own name" thinking.
- Name changes motivated by ego/convenience, not architecture.

### Author blind spots
- Modern brand "gatekeeper" can be a platform/CMS rule, not just a committee.
- Digital channels make channel conflict more fluid (DTC vs retail).

### Easily confused with
- `aaker-relation-select-separation` (decision) — this skill is the *risk filter* applied after.
