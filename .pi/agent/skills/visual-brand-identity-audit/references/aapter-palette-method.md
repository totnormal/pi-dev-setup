## Steps

1. Identify current palette roles:
- brand primary
- secondary/support
- neutrals
- semantic/status colors
- accent/highlight

2. Assess behavior, not only swatches:
- tint/shade scalability
- saturation ceilings
- contrast pair reliability
- UI state compatibility (default/hover/active/error/success/info)

3. Build governance:
- assign role ownership per color token
- define usage ratios (for example 60/30/10 or equivalent rationale)
- set forbidden pairings
- define minimum contrast thresholds

4. Test in context:
- logo lockups
- text on backgrounds
- CTA emphasis
- charts/data visuals
- mobile and desktop UI states
- print equivalents where needed

5. Flag risks:
- color-blind ambiguity
- low-light readability
- color drift across media
- over-reliance on accent color

## Deliverables

- role-mapped palette table
- approved tint/shade ramps
- semantic state matrix
- contrast exceptions list
- color governance recommendations
