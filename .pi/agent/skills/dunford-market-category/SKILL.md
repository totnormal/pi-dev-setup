# Choose the Market Category That Makes Strengths Obvious

## R — Original Passage (Reading)

> Picking a market is like giving customers an answer to the question, What are you?
>
> — April Dunford, Step 8: Find a Market Frame of Reference

---

## I — Methodology Skeleton (Interpretation)

A market category is a shortcut that triggers assumptions about competitors, features, pricing, and purchase criteria. Choose a category that makes your differentiated value obvious to best-fit customers. Sometimes that is the original category; sometimes it is an adjacent category; rarely, it is a new category you must create.

---

## A1 — Application in the Book (Past Application)

An email-for-lawyers product confused prospects because email implied calendars and inbox expectations, while its value was secure context-aware file sharing. Reframing it as team collaboration software made the value easier to understand.

## B — Boundary

### Do not use this skill when

- Do not ask customers to be positioning experts; use feedback cautiously.
- Do not pick a trendy category merely because it is hot.
- Do not create a new category unless existing categories genuinely fail.

### Common failure modes from Dunford's books

- Treating positioning as copywriting rather than strategic context.
- Talking about features before clarifying alternatives and value.
- Using generic trends, generic problems, or generic proof.
- Letting the buyer infer the purchase criteria alone.
