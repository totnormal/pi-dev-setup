# LLM Council

## Extended Details



Use this skill when you want a local multi-model workflow that fans a prompt out to several models, compares the responses, and synthesizes a final answer.

## What it does

- Sends the same task to multiple models
- Compares, ranks, and cross-reviews their outputs
- Produces a consolidated final answer

## Good fits

- Hard questions where model disagreement is useful
- Research tasks that benefit from multiple opinions
- Answer synthesis and adjudication

## Local repo

This skill mirrors the [`guy-hartstein/company-research-agent`](https://github.com/guy-hartstein/company-research-agent) project style of multi-agent orchestration and is intended to keep the repo discoverable from all local CLIs.
