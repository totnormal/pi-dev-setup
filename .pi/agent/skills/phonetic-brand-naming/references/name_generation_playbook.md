# Name Generation Playbook (Variety + Taste + Territory)

Use this to generate names that are not just "many", but meaningfully diverse across semantic and sonic territory.

Positioning reminder: names live in context. If category/alternatives are unclear, force clarity before naming.

## Choose Name Styles Intentionally

Allowed name styles (select 2-4 for the brief):

- Descriptive: says what it is (high clarity, low distinctiveness).
- Suggestive: hints at outcome/benefit (good balance for many categories).
- Metaphoric: imagery/analogy (memorable when chosen well).
- Arbitrary: real word with no direct link (high distinctiveness, needs brand building).
- Coined: invented but pronounceable (high control over sound).
- Portmanteau/Compound: combines morphemes (clarity + distinctiveness if done cleanly).
- Acronym/Initialism: usually a last resort unless you already have authority.
- Founder/Place-based: works when founder/place has equity or story.

Heuristic: if the user needs immediate comprehension (new category, low attention, performance marketing), lean toward descriptive/suggestive/clean compounds. If they need long-term defensibility and brand-building, lean toward coined/metaphoric/arbitrary, but keep phonetics tight.

## Carve Out "Phonetic Territory" vs Competitors

Before generating, analyze competitor names quickly (even informally):

- Syllable count and stress pattern
- "Hardness" (plosives) vs "softness" (nasals/liquids)
- Vowel palette (bright vs round)
- Endings (open vowels like -a/-o vs hard stops like -t/-k)
- Common suffix/prefix patterns in the category

Then choose an intentional offset, unless strategy demands matching category cues.

## Bucket Guidance (6 Names Each)

### 1) Suggestive (Strategy-Fit)

Goal: strongly aligned to the differentiated value, without becoming generic.

Do:

- Encode the outcome ("clarity", "signal", "anchor") rather than the mechanism ("AI", "cloud", "platform").
- Use one strong idea; avoid feature soup.

Avoid:

- Obvious category words unless strategically necessary.
- Overused tech suffixes that reduce distinctiveness.

### 2) Metaphor / Imagery

Goal: create a memorable mental picture that supports the desired emotion.

Do:

- Pick metaphors that map to the job-to-be-done (speed, safety, guidance, craft, leverage).
- Prefer image-rich nouns that still sound good when spoken.

Avoid:

- Metaphors that imply the opposite (fragile, slow, deceptive, childish).
- Overused startup metaphors (unless you can make it fresh).

### 3) Coined (Natural Phonotactics)

Goal: invented names that feel like they could already be words in the language.

Do:

- Use common syllable shapes (`CV`, `CVC`, `CV-CV`, `CVC-CV`).
- Anchor with familiar morphemes or sound-shapes that cue the category or personality.
- Keep spelling aligned with pronunciation (avoid gotchas).

Avoid:

- Random letter strings (no "zqvry").
- Excessive vowels or stacked consonants.
- Ambiguous vowel digraphs (`ae`, `eo`, `ui`) unless you control the audience and it is intentional.

### 4) Compound / Portmanteau (Clean, Non-Clunky)

Goal: clarity + distinctiveness with minimal pronunciation friction.

Do:

- Keep it short; 2 morphemes max unless the brief demands more.
- Smooth the join (drop letters if needed) so it doesn't read like a smashed URL.
- Ensure the intended parse is obvious on first read.

Avoid:

- Hard-to-parse junctions and double meanings that confuse.
- "Descriptor + AI" style constructions unless the brand needs brute clarity.

### 5) Premium Minimal (Short Names)

Goal: compact, distinctive, high "wordmark quality".

Do:

- Optimize for sayability and spelling, not just shortness.
- Use strong rhythm; avoid looking like an acronym unless desired.

Avoid:

- Names that require pronunciation explanation every time.
- Short strings that are visually/sonically generic.

## Extension / Naming Architecture Patterns

Default patterns to propose (pick one):

- Brand + Descriptor: `Brand` / `Brand Flow` / `Brand Assist`
- Brand + Model: `Brand One` / `Brand Two`
- Brand + Tier: `Brand Basic` / `Brand Pro` / `Brand Team`
- Family theme: parent brand + themed sub-brands (only if it won't create future constraints)

Check:

- Can it verb? (optional but powerful)
- Can it pluralize?
- Does it create awkward tongue-twisters in product naming?
