# Phonetics Toolkit (Practical, Sound-First)

Use this as a helper to produce names that perform in the spoken word (first-read pronunciation, conversation hearability, phone spelling).

## "Sounds Like" Formatting

Goal: give a stranger an immediate, low-effort pronunciation cue.

Rules:

- Use 2-4 chunks (syllables) separated by hyphens.
- Capitalize the stressed chunk (primary stress), e.g., `KAH-ree-oh`, `VER-dan`, `pro-ME-thee`.
- Avoid technical phonetic symbols in the "sounds like" line; save that for IPA.

## IPA Guidance (Use Where Feasible)

Goal: precise phonetic reference, without pretending certainty you don't have.

Rules:

- Default accent: General American English unless the user specifies a different target.
- Use slashes for phonemic IPA: `/.../`.
- Mark primary stress with `ˈ` before the stressed syllable: `/ˈ.../`.
- If you're not confident, add a short uncertainty note (do not guess confidently).

Common IPA cheatsheet (not exhaustive):

- `i` (ee) as in "see"
- `ɪ` (ih) as in "sit"
- `eɪ` (ay) as in "say"
- `ɛ` (eh) as in "set"
- `æ` (a) as in "cat"
- `ɑ` (ah) as in "father" (US)
- `ʌ` (uh) as in "cut"
- `oʊ` (oh) as in "go"
- `ʊ` (oo) as in "book"
- `u` (oo) as in "food"
- `aɪ` (eye) as in "my"
- `aʊ` (ow) as in "now"
- `ɔɪ` (oy) as in "boy"
- `ʃ` (sh), `tʃ` (ch), `ʒ` (zh), `dʒ` (j)

## Rhythm, Stress, and "Mouth-Feel" Heuristics

Use these as heuristics, not laws.

### Stress pattern

- 2 syllables:
  - Stress on 1st (TROchee: `ˈDA-ta`) often feels direct, decisive, "brand-like".
  - Stress on 2nd (iAMB: `daˈTA`) can feel a bit more "verb-like" or energetic, but risks mis-stress in English.
- 3 syllables:
  - Aim for a clear primary stress and avoid multiple plausible stresses.

Red flags:

- Names that can be stressed two ways without guidance (creates inconsistent word-of-mouth).
- Names that look like they want one stress but speak like another.

### Consonant texture (sound symbolism)

- Plosives `p t k b d g`: punchy, decisive, engineered, "assertive".
- Fricatives `s f v z ʃ`: fast, sleek, precise, "high-definition".
- Nasals `m n ŋ`: warm, human, friendly, "safe".
- Liquids `l r`: fluid, premium, "smooth".

### Vowel palette (very rough)

- Front vowels (`i`, `ɪ`, `eɪ`, `ɛ`, `æ`): bright, quick, sharp, lighter.
- Back/rounded vowels (`oʊ`, `u`, `ʊ`, `ɔ`): round, weighty, premium, slower.
- Open vowels (`ɑ`, `æ`): bold, open, confident.

### Cluster discipline

- Avoid dense consonant clusters, especially at the start (e.g., `xtr-`, `pt-`, `tsk-`).
- Avoid ambiguous letter clusters that invite multiple parses (e.g., `ae`, `eo`, `ii`, `y` near vowels).

## Spoken-Word Performance Checks

### Pronounceability (first-read)

Prefer:

- Common grapheme-to-sound mappings (especially for the target language).
- Simple syllable shapes: `CV`, `CVC`, `CV-CV`, `CVC-CV`.

Avoid:

- Silent letters and "gotcha" spellings.
- Rare digraphs unless the audience is highly educated and it's strategically justified.

### Hearability (conversation)

Prefer:

- Distinct initial sounds (helps recall and reduces confusion).
- Clear vowel contrasts (avoid mushy mid-vowel soup).

Avoid:

- Names that collapse into common words at speed.
- Names that differ from competitors by only one subtle phoneme.

### Spellability (phone test)

Prefer:

- One obvious spelling for the sound.
- Avoid `ph` for /f/ unless you want a classical/academic cue.
- Avoid mixing `c/k/q` ambiguously for /k/ without a reason.
- Avoid ambiguous vowels where multiple spellings are equally plausible.

## Accent Tolerance Heuristics

You cannot fully solve accent variance, but you can avoid common breakpoints.

Guidelines:

- If targeting global English, avoid relying on `r`-coloring, subtle vowel distinctions, or tricky consonants like `θ`/`ð`.
- If targeting US + UK, watch for different vowel realizations (`ɑ` vs `ɒ`, etc.) and ensure the name still feels coherent.
- If targeting non-native speakers, reduce consonant clusters and avoid rare sounds.

## Competitor "Phonetic Territory" Mapping (Quick Method)

When competitors are provided, map them quickly before generating names:

- Syllables + stress (e.g., 2 syllables, stress on 1st)
- Start sound (vowel vs consonant; plosive vs fricative vs nasal)
- Vowel palette (bright vs round)
- Ending sound (hard stop vs open vowel vs nasal)
- Overall texture (soft vs hard; warm vs cool; modern vs classic)
- Name style (descriptive/suggestive/coined/etc.)

Then choose an intentional counter-position in sound, not just meaning.

Example (conceptual):

- Competitors are soft, vowel-heavy, ending in `-ia`/`-io`.
- Consider a tighter, consonant-led name with a clean stop, if it still fits the strategy.
