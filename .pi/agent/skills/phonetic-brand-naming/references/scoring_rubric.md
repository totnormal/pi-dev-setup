# Scoring Rubric (0-10) + Common Failure Modes

Use consistent anchors:

- 9-10: exceptional, low-friction, unusually strong
- 7-8: strong, minor fixable issues
- 5-6: workable, but meaningfully compromised
- 3-4: weak, high friction or off-strategy
- 0-2: fails the bar (do not recommend)

Before scoring, write brief justifications (one line per criterion) so scores don't feel arbitrary.

## Criteria Definitions

### Strategy Alignment

Does the name fit the Strategy Spine (positioning, audience, differentiation, personality, desired emotion)?

Common failure modes:

- Sounds cute when the brand must be credible/serious.
- Sounds premium when the brand must be warm/accessible.
- Semantics pull toward the wrong category (misframes you).

### Pronounceability (First-Read Accuracy)

Can a stranger say it correctly after seeing it once?

Common failure modes:

- Unclear vowel mapping (multiple plausible pronunciations).
- Dense consonant clusters.
- Silent letters / tricky digraphs.

### Hearability (Conversation Capture)

Will someone catch it accurately in a sentence at normal speed?

Common failure modes:

- Sounds like a common word (or multiple words).
- Minimal difference vs competitor names.
- Low-contrast syllables ("mushy" mid-vowel soup).

### Spellability (Over-the-Phone)

Can someone spell it from hearing it once without a long clarification dance?

Common failure modes:

- Multiple plausible spellings for the same sound.
- Requires constant: "It's X with a Y" explanations.
- Uses uncommon letter combos for the audience.

### Memorability

Will people remember it after short exposure? (rhythm, distinctiveness, imagery)

Common failure modes:

- Generic benefit word (forgettable).
- No imagery, no sonic hook, no rhythm.
- Looks like a dozen other startup names.

### Distinctiveness

Is it clearly differentiated from generic category terms and competitor naming patterns?

Common failure modes:

- Too descriptive (blends in).
- Too close to the dominant naming pattern in the category.
- Uses obvious overused suffixes/prefixes (unless deliberately chosen).

### Sonic Appropriateness (Sound Symbolism)

Do the sounds support the desired feeling (warm, sharp, premium, playful, technical, etc.)?

Common failure modes:

- "Hard" consonants for a brand that must feel safe/gentle.
- Soft, open vowels for a brand that must feel precise/engineered.
- Rhythm feels childish for an enterprise buyer.

### Extensibility

Does it work as:

- a parent brand
- product/feature names
- a verb ("We ___ it")
- a community name ("___ users")
- taglines and sub-brands

Common failure modes:

- Too narrow or literal (can't stretch).
- Awkward pluralization/verbing.
- Naming architecture becomes clunky (e.g., "Name Pro Max Ultra").

### Risk Flags (Reverse Score)

Score higher when risk is lower. Consider:

- Confusability with competitors or common words
- Negative connotations (including cross-language risks where specified)
- Pronunciation disagreement risk (multiple plausible readings)
- Cultural sensitivity risk
- Internal brand system conflicts (doesn't fit existing brand codes)
