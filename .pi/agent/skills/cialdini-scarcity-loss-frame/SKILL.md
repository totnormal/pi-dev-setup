# Scarcity and Loss Frame

## R — Reading

> “The way to love anything is to realize that it might be lost.”
>
> — Robert B. Cialdini, Chapter 7: Scarcity

---

## I — Methodology skeleton (Interpretation)

1. Scarcity increases perceived value because people dislike losing freedom and missing unique opportunities.
2. It is especially strong when scarcity is new, competitive, or tied to a specific loss.
3. Ethical scarcity makes real constraints clear: what is limited, why, when it ends, and what happens if the user waits.
4. The goal is informed urgency, not panic.

---

## A1 — Application in the source

### Case 1: Mesa Mormon temple access
- **Problem**: A normally restricted temple briefly opened to the public; interest rose because access was limited.
- **Methodology use**: Temporary availability changed perceived value.
- **Result**: Deadlines work when they reflect real access constraints.

### Case 2: Romeo and Juliet effect
- **Problem**: Interference with romantic freedom can intensify desire.
- **Methodology use**: Restriction can trigger reactance.
- **Result**: Heavy-handed scarcity can backfire by making people resist control.

## B — Boundary

### Do not use this skill when

- Never fabricate limited supply, fake timers, false waitlists, or “only X left” claims.
- Do not use in grief, health, financial distress, or other vulnerable contexts without extra safeguards.
- If scarcity is the only reason to buy, recommend improving value first.

### Global Cialdini safety constraints

- Truthful evidence beats persuasion technique; if the evidence is weak, say so.
- Preserve meaningful choice; avoid hidden defaults, fake constraints, or social pressure that makes refusal unsafe.
- Name the influence mechanism in the answer so the user can judge it consciously.
